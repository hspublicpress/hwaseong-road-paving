다른 지역에서 포장 발주 주기 지도 만들기

이 지도는 나라장터에 공개된 공사 발주 이력으로 "같은 자리가 얼마나 자주 다시 포장되는지"를 보여줍니다. 화성시로 만들었지만, 아래 순서를 따르면 다른 시·군도 같은 방식으로 볼 수 있습니다. 코드는 GitHub 저장소에 있습니다.

2. 준비할 키

  1. 공공데이터포털 인증키 1개. 위 두 서비스에 각각 "활용신청"을 하면 같은 키로 호출됩니다. 개발계정은 하루 1,000회까지라 10년치 수집에 하루면 충분합니다.
  2. NCP Maps: 콘솔에서 Application을 만들고 Web Dynamic Map과 Geocoding을 켭니다. 서비스 URL에 지도를 올릴 주소(예: GitHub Pages 주소)를 등록해야 지도가 뜹니다.

3. 실행 순서

저장소의 scripts/를 시군 이름만 바꿔 순서대로 실행합니다. 모든 스크립트는 --city 시군명을 받습니다.

python scripts/01_fetch_g2b.py --city 수원시 --from 2016-01   # 나라장터 수집(낙찰·입찰공고)
python scripts/02_repeat_roads.py --city 수원시               # 공고명 기준 반복 도로 1차 집계
python scripts/03a_fetch_notices.py --city 수원시             # 공고문 첨부 다운로드
python scripts/03b_extract_text.py --city 수원시              # 본문 추출
python scripts/03c_clip_nodelink.py --city 수원시             # 표준노드링크를 시군 경계로 자르기
python scripts/03d_parse_notices.py --city 수원시             # 지번·도로명·연장·면적 추출
python scripts/04_geocode_segments.py --city 수원시           # 좌표·선형 만들기
python scripts/05_intervals.py --city 수원시                  # 재발주 간격 계산, 웹 데이터 생성

끝나면 web/ 폴더를 정적 호스팅(GitHub Pages 등)에 올리고, 상단 드롭다운에서 시군을 고르면 됩니다.

4. 지역마다 손봐야 하는 것

  • 기관명: 나라장터의 수요기관명이 "○○시"로 검색됩니다. 특례시·구 설치 등으로 기관명이 바뀐 적이 있으면 scripts/common.py의 별칭 목록에 추가합니다.
  • 공고명 키워드: 지역마다 "덧씌우기", "포장도 보수", "보도블록" 등 쓰는 말이 다릅니다. 1차 집계 결과를 보고 common.py의 키워드와 제외어를 조정합니다.
  • 공고문 양식: 지자체마다 "공사현장", "사업위치", "위치" 등 표기가 다릅니다. 03d_parse_notices.py의 정규식을 공고문 몇 건을 열어 보고 맞춥니다.
  • 소액 공사: 나라장터에 올라오지 않는 소액 수의계약은 시·군 홈페이지의 계약정보 공개에서 따로 받아야 합니다.

5. 결과를 읽을 때 주의

  • 색은 "같은 자리에 다시 발주된 최소 간격"입니다. 위치 정확도 A(지번)만 간격 계산에 쓰고, 도로 전체·읍면동 단위로만 잡힌 건은 지도에 표시만 하고 간격은 계산하지 않습니다.
  • 짧은 간격이 곧 중복 포장은 아닙니다. 상하수도·가스·통신 굴착 뒤 복구, 1공구·2공구 분할, 부분 보수가 섞여 있으니 공고문 링크로 공사개요를 확인해야 합니다.
  • 발주일은 입찰공고일 기준입니다. 실제 시공 시점과는 수개월 차이가 날 수 있습니다.
